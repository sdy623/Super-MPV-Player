# MPV Complete 2.1.0 — 综合播放器开放版

本版以已提交核心 `49b2f5d` 为基础，保留主题、蓝光菜单、章节、时间轴、Omniphony 可选接入与 DCP。

## 更新
- HLG Windows 杜比处理保留 FP16 scRGB 精度；PQ/P7 MEL 保留原有色彩契约，FEL 由 gpu-next 重建。
- GPU 共享纹理使用轮转纹理环与可用时的 GPU fence；不使用实验性输入缓冲池。
- DV 精确跳转跳过不可见帧的 Windows 处理，保留 HEVC 解码、RPU/EL 配对和末帧处理。
- 通用 DCP XYZ 高精度色彩管理、系统 ICM、可选影院白点适配；不包含 Ray/CPL 特例，不经过杜比桥。
- 英文详细统计同时显示源格式、RPU、实际处理路径和 SDR 输出。

## 已知限制：暂停恢复仍可能掉帧
本版不是“4K60 Windows DV 零掉帧修复版”。116.512 秒 HLG 样本曾完成零掉帧测试，但实际启动器的六次暂停恢复完整复测记录到 **30 帧输出丢帧、0 解码丢帧、无杜比回退**。这些掉帧不能解释为仅 1 帧，也不能归咎于机械盘：复现时媒体已缓存到结尾。
卡顿时可选择原 gpu-next 映射；它与 Windows 杜比处理是不同路径。
F1 P7 MEL 的菜单、方向选择、章节、跳转和有声代表片段已验证；不是整部电影长测。Reply DCP 的 274.708 秒完整测试零解码/输出丢帧，早前另一次测试记录过 3 帧启动输出丢帧。

## 外部依赖
Dolby 专有处理依赖用户通过 Microsoft Store/设备厂商合法安装的组件，并进行依赖检测。SDR 内屏的结果仍是 SDR，不是物理 DV HDR 输出。
Omniphony 引擎与解码桥、libfreemkv 及其桥程序由用户另行安装；保留下载入口和 Studio 库优先，不随包分发。PCM/DCP 不改原解码器，音频与视频模式独立。
P9 / CB1 开放处理后端尚未完成，不宣称本版已支持。

## 安装
使用英文/ASCII 安装目录。安装器不自动启动播放、不改文件关联、不关闭杀毒或添加排除；升级保留用户配置。提供安装包、对应播放器源码和原生依赖源码附件。
